# 组件：记忆结构规范

> AHE 组件类型：Long-term Memory
> 收益预期：+5.6pp（论文数据，最高收益！）
> 原则：记忆结构是硬结构，换了模型照样好使

## 记忆层级

### 1. 日常记忆（短期）
- 位置：`memory/YYYY-MM-DD.md`
- 内容：当天发生的事、临时笔记、任务记录
- 保留期：7天内有价值，之后提炼到 MEMORY.md

### 2. 核心记忆（长期）
- 位置：`MEMORY.md`
- 内容：用户的偏好、重要决策、持久事实
- 更新频率：每周审查一次，提炼日常记忆

### 3. 工具记忆（环境特定）
- 位置：`TOOLS.md`
- 内容：工具配置、路径、踩坑记录
- 更新频率：发现新工具/配置时立即更新

### 4. AHE 记忆（进化特定）
- 位置：`D:\longxiaqiang\tools\ahe\evidence/`
- 内容：任务分析、模式识别、进化记录
- 更新频率：每次进化循环

## 记忆写入规则

### 必须写入的场景
- 用户说"记住"/"remember" → 立即写文件
- 做了重要决策 → 写入 MEMORY.md
- 发现工具新用法 → 写入 TOOLS.md
- 任务失败 → 写入 AHE evidence

### 写入原则
1. **写文件 > 脑内记忆**：文件能活过session重启，脑内记忆不行
2. **具体 > 模糊**：写"用 vxtwitter API 替代 web_fetch"，不要写"记住X的抓取方法"
3. **有时间戳**：每条记录带日期
4. **可搜索**：用关键词，不用长句

## 记忆审查流程

### 每日（心跳期间）
1. 检查今天的 memory/YYYY-MM-DD.md
2. 有重要事件？→ 追加到 MEMORY.md

### 每周
1. 读取过去7天的 memory/*.md
2. 提炼有价值的到 MEMORY.md
3. 清理过期的日常记忆

### 每月
1. 审查 MEMORY.md，删除过时信息
2. 审查 TOOLS.md，更新工具状态
3. 审查 AHE evidence/overview.md
